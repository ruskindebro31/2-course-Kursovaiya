# Candels — интернет-магазин свечей

Курсовой проект по дисциплине **«Технология разработки программного обеспечения»**  
по траектории **В: React SPA + AJAX + JWT + WebSocket**

---

## 🧰 Стек технологий

- **Backend:** Django, DRF, SimpleJWT, Django Channels
- **Frontend:** React, Vite, Axios, Zustand
- **База данных:** SQLite (по умолчанию), PostgreSQL (опционально)
- **Документация API:** Swagger UI (`drf-spectacular`)
