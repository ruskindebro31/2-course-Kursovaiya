# ДЕТАЛЬНЫЙ ПЛАН РЕАЛИЗАЦИИ ТРАЕКТОРИИ В
## Candels Project - Расширенное SPA приложение

### Общая характеристика траектории В

**Тип приложения**: Расширенное SPA-приложение с продвинутой клиентской логикой
**Технологии**: React SPA + AJAX + JWT + WebSocket
**Сложность**: Очень высокая
**Объем кода**: ~5000+ строк
**Оценка**: «отлично» + автомат на экзамене

### Особенности реализации:

1. Все возможности траектории Б:
   - Разделение на бэкенд (Django REST API) и фронтенд (React SPA)
   - JWT-аутентификация (access + refresh токены)
   - Полноценное REST API с CRUD-операциями

2. Расширенная клиентская логика:
   - Оптимистичные обновления
   - Кэширование запросов
   - Продвинутая работа с API

3. Дополнительный функционал:
   - WebSocket (Django Channels)
   - Real-time уведомления
   - Система комментариев с моментальным отображением
   - Система избранного с оптимистичным обновлением UI

### Технические требования:

#### Backend (Django REST API):
- Django 4.2+
- Django REST Framework
- JWT Authentication (djangorestframework-simplejwt)
- Django Channels для WebSocket
- PostgreSQL/SQLite база данных
- Django CORS Headers

#### Frontend (React SPA):
- React 18+
- React Router v6+
- React Query для кэширования
- Axios для HTTP запросов
- Socket.IO client для WebSocket
- JWT decode для токенов
- React Hook Form для форм
- React Toastify для уведомлений
