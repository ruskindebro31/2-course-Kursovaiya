# АРХИТЕКТУРНАЯ ДИАГРАММА
## Candels Project - Интернет-магазин свечей ручной работы

### Общая архитектура системы

Архитектура проекта Candels построена по принципу клиент-серверного приложения с разделением на бэкенд и фронтенд части. Это обеспечивает гибкость, масштабируемость и четкое разделение ответственности между компонентами.
