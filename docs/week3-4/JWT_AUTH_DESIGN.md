# ПРОЕКТИРОВАНИЕ СИСТЕМЫ АУТЕНТИКАЦИИ JWT
## Candels Project - Интернет-магазин свечей ручной работы

## Общее описание

Система аутентификации Candels основана на технологии JWT (JSON Web Tokens) и реализована с использованием библиотеки `djangorestframework-simplejwt`. Она обеспечивает безопасное управление сессиями пользователей с поддержкой ролевой модели (покупатель, мастер, администратор).
