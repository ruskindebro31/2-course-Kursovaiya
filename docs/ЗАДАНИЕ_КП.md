**3. Задачи:**

**3.1. Анализ прикладной задачи и методов её решения**

- Провести предпроектное обследование предметной области.
- Выполнить анализ бизнес-процессов и сформулировать требования к программному обеспечению.
- Обосновать выбор технологического стека в соответствии с выбранной траекторией: (записать свою выбранную траекторию)
  - Траектория А: Django, Django Templates, Bootstrap, SQLite/PostgreSQL.
  - Траектория Б: Django, Django REST Framework, React, JWT, PostgreSQL.
  - Траектория В: Django, Django REST Framework, React, Django Channels, WebSocket, JWT, PostgreSQL, Redis.
- Проанализировать существующие аналоги и обосновать необходимость разработки.

**3.2. Разработка алгоритмов решения задачи**

- Разработать модель предметной области (Domain Model).
- Спроектировать Use Case диаграмму и спецификации прецедентов.
- Разработать ER-диаграмму базы данных.
- Спроектировать архитектуру приложения в соответствии с выбранной траекторией: (записать свою выбранную траекторию)
  - Траектория А: архитектура Django MTV.
  - Траектория Б: клиент-серверная архитектура с REST API.
  - Траектория В: клиент-серверная архитектура с WebSocket.
- Разработать алгоритмы основных сценариев (регистрация, аутентификация, CRUD-операции).

**3.3. Реализация программного кода**

- Реализовать модели данных с учётом связей между таблицами.
- Реализовать систему аутентификации: (записать свою выбранную траекторию)
  - Траектория А: сессионная аутентификация.
  - Траектория Б, В: JWT-аутентификация (access/refresh токены).
- Реализовать бизнес-логику:
  - Траектория А: представления (views) и шаблоны (templates).
  - Траектория Б, В: REST API (ViewSet, Serializer) и React-приложение.
- Реализовать дополнительные функции согласно выбранной траектории:
  - Траектория А: AJAX-запросы для динамического обновления контента.
  - Траектория Б: полноценное SPA с маршрутизацией и управлением состоянием.
  - Траектория В: WebSocket (Django Channels) для real-time уведомлений, оптимистичные обновления, кэширование.

**3.4. Отладка и тестирование программного кода**

- Провести модульное тестирование ключевых компонентов (модели, API, компоненты React).
- Выполнить интеграционное тестирование взаимодействия между слоями.
- Провести системное тестирование сценариев использования.
- Для траектории В: выполнить нагрузочное тестирование WebSocket-соединений.
- Зафиксировать результаты тестирования в отчёте.
