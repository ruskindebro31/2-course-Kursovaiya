## 1. Тема проекта

**Интернет-магазин свечей ручной работы «Candels»** (траектория В)

---

## 2. Цель

Повышение уровня профессиональной подготовки путём углубления и закрепления теоретических знаний и практических навыков, приобретённых в результате изучения дисциплины «Технология разработки программного обеспечения», а также формирование компетенций в области проектирования, разработки и документирования современных веб-приложений с использованием фреймворка Django в рамках выбранной траектории выполнения.

---

## 3. Задачи

### 3.1. Анализ прикладной задачи и методов её решения

- Провести предпроектное обследование предметной области интернет-магазина handmade-свечей.
- Выполнить анализ бизнес-процессов и сформулировать требования к программному обеспечению.
- Обосновать выбор технологического стека в соответствии с выбранной траекторией:

**Траектория В:** Django, Django REST Framework, React, Django Channels, WebSocket, JWT, SQLite/PostgreSQL, Redis (опционально).

- Проанализировать существующие аналоги (Etsy, Wildberries handmade, локальные мастерские) и обосновать необходимость разработки специализированной платформы.

### 3.2. Разработка алгоритмов решения задачи

- Разработать модель предметной области (Domain Model).
- Спроектировать Use Case диаграмму и спецификации прецедентов.
- Разработать ER-диаграмму базы данных.
- Спроектировать архитектуру приложения:

**Траектория В:** клиент-серверная архитектура с REST API и WebSocket.

- Разработать алгоритмы основных сценариев (регистрация, аутентификация, CRUD-операции, оформление заказа, real-time уведомления).

### 3.3. Реализация программного кода

- Реализовать модели данных с учётом связей между таблицами (User, Profile, Category, Candle, Review, Favorite, Order, Cart, Notification).
- Реализовать систему аутентификации:

**Траектория В:** JWT-аутентификация (access/refresh токены), хранение в localStorage, автоматическое обновление.

- Реализовать бизнес-логику:

**Траектория В:** REST API (ViewSet, Serializer) и React SPA (Vite, React Router, TanStack Query).

- Реализовать дополнительные функции согласно траектории В:
  - WebSocket (Django Channels) для real-time уведомлений и отзывов;
  - оптимистичные обновления UI (избранное, отзывы);
  - кэширование запросов (React Query);
  - пагинация, фильтрация и поиск на клиенте.

### 3.4. Отладка и тестирование программного кода

- Провести модульное тестирование ключевых компонентов (API, аутентификация, избранное).
- Выполнить интеграционное тестирование взаимодействия frontend ↔ backend.
- Провести системное тестирование сценариев использования (каталог, заказ, профиль).
- Зафиксировать результаты тестирования в отчёте.
