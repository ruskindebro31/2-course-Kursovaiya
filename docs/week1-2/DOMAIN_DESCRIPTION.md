# ОПИСАНИЕ ПРЕДМЕТНОЙ ОБЛАСТИ
## Candels Project - Интернет-магазин свечей ручной работы

### Общее описание
Candels представляет собой специализированный интернет-магазин по продаже свечей ручной работы. Платформа объединяет мастеров-умельцев, создающих уникальные свечи, с покупателями, ценящими ручную работу и индивидуальность. Сайт предоставляет возможность не только покупки, но и персонализации свечей, общения с мастерами, а также участия в сообществе любителей handmade-продуктов.

### Целевая аудитория
- **Покупатели**: Люди, интересующиеся handmade-товарами, подарками ручной работы, декоративными свечами
- **Мастера**: Умельцы, создающие свечи ручной работы и желающие продавать свои изделия
- **Коллекционеры**: Любители коллекционировать уникальные свечи
- **Корпоративные клиенты**: Бизнесы, заказывающие свечи для мероприятий или в качестве подарков

### Основные функции системы

#### 1. Управление пользователями
- Регистрация и аутентификация (покупатели и мастера)
- Профили пользователей с персонализацией
- Система ролей (покупатель, мастер, администратор)
- Управление настройками приватности

#### 2. Управление продуктами
- Каталог свечей ручной работы
- Детальное описание каждой свечи (материалы, ароматы, размеры)
- Фотогалерея изделий
- Система категорий и тегов
- Поиск и фильтрация по параметрам

#### 3. Система заказов
- Корзина товаров
- Оформление заказа
- Выбор способов доставки и оплаты
- Отслеживание статуса заказа
- История заказов

#### 4. Система взаимодействия
- Отзывы и оценки товаров
- Вопросы к мастерам
- Комментарии к товарам
- Чат с мастером для персонализации

#### 5. Личный кабинет мастера
- Управление своими товарами
- Просмотр заказов своих изделий
- Статистика продаж
- Настройка профиля мастера

#### 6. Персонализация
- Заказ индивидуальных свечей
- Настройка параметров (аромат, цвет, форма)
- Предварительный просмотр персонализации

#### 7. Уведомления
- Real-time уведомления о заказах
- Уведомления о новых отзывах
- Уведомления о статусе заказа

### Ключевые сущности системы

#### 1. Пользователь (User)
- Уникальный идентификатор
- Электронная почта (уникальная)
- Имя пользователя
- Пароль (хэшированный)
- Роль в системе (покупатель/мастер/админ)
- Дата регистрации
- Статус активности

#### 2. Профиль (Profile)
- Связь с пользователем
- Аватар
- Биография
- Контактная информация
- Адрес доставки
- Настройки уведомлений
- Для мастеров: портфолио, специализация

#### 3. Категория (Category)
- Название категории (ароматические, декоративные, церемониальные и т.д.)
- Описание
- Иконка или изображение

#### 4. Свеча (Candle)
- Название
- Описание
- Мастер (создатель)
- Категория
- Цена
- Наличие
- Размеры и вес
- Используемые материалы
- Ароматы
- Цвета
- Время горения
- Фотографии
- Статус публикации

#### 5. Заказ (Order)
- Покупатель
- Список товаров
- Общая сумма
- Статус заказа
- Адрес доставки
- Способ оплаты
- Способ доставки
- Дата создания
- Дата обновления статуса

#### 6. Отзыв (Review)
- Пользователь
- Свеча
- Оценка (1-5 звезд)
- Текст отзыва
- Дата создания

#### 7. Персонализированный заказ (CustomOrder)
- Пользователь
- Описание требований
- Предпочтения по аромату, цвету, форме
- Бюджет
- Сроки
- Статус обработки запроса

#### 8. Уведомление (Notification)
- Получатель
- Отправитель (система или пользователь)
- Тип уведомления
- Содержание
- Статус прочтения
- Дата создания

### Бизнес-процессы

#### Процесс регистрации пользователя
1. Пользователь переходит на страницу регистрации
2. Выбирает тип аккаунта (покупатель или мастер)
3. Заполняет регистрационную форму
4. Система проверяет уникальность данных
5. Отправляет подтверждение на email
6. Пользователь подтверждает регистрацию
7. Создается профиль пользователя

#### Процесс добавления свечи мастером
1. Мастер авторизуется в системе
2. Переходит в личный кабинет
3. Нажимает "Добавить новую свечу"
4. Заполняет форму с деталями изделия
5. Загружает фотографии
6. Устанавливает цену и количество
7. Отправляет на модерацию
8. Администратор проверяет и публикует

#### Процесс покупки свечи
1. Покупатель просматривает каталог
2. Выбирает интересующую свечу
3. Добавляет в корзину
4. Переходит к оформлению заказа
5. Указывает данные для доставки
6. Выбирает способ оплаты
7. Подтверждает заказ
8. Получает подтверждение и отслеживание

#### Процесс персонализации
1. Покупатель выбирает базовую свечу для персонализации
2. Переходит к настройке параметров
3. Выбирает аромат, цвет, дополнительные элементы
4. Видит предварительный просмотр
5. Отправляет запрос мастеру
6. Мастер связывается для уточнения деталей
7. Создается индивидуальный заказ

#### Процесс взаимодействия через отзывы
1. Покупатель получает товар
2. Переходит к оставлению отзыва
3. Ставит оценку и пишет комментарий
4. Отзыв появляется моментально (оптимистичное обновление)
5. Мастер получает уведомление
6. Другие покупатели видят отзывы

### Нефункциональные требования

#### Производительность
- Время загрузки страницы не более 2 секунд
- Поддержка одновременной работы 500+ пользователей
- Кэширование часто запрашиваемого контента

#### Надежность
- Время безотказной работы 99.9%
- Резервное копирование данных
- Восстановление после сбоев

#### Безопасность
- Защита от SQL-инъекций
- Защита от XSS-атак
- Шифрование паролей
- Безопасная обработка платежей
- JWT-токены для аутентификации

#### Масштабируемость
- Горизонтальное масштабирование
- Поддержка облачных технологий
- Возможность добавления новых категорий
