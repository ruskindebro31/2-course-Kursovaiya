# USE CASE ДИАГРАММА
## Candels Project - Интернет-магазин свечей ручной работы

### Участники системы (Actors)

#### 1. Гость (Guest)
Пользователь, не прошедший аутентификацию

#### 2. Покупатель (Customer)
Зарегистрированный пользователь, желающий приобрести свечи

#### 3. Мастер (Master)
Зарегистрированный пользователь, создающий и продающий свечи

#### 4. Администратор (Admin)
Пользователь с правами управления системой

#### 5. Система уведомлений (Notification System)
Автоматизированная система отправки уведомлений

### Use Cases

#### Для Гостя:
- Просмотр каталога свечей
- Просмотр отдельной свечи
- Поиск свечей по параметрам
- Фильтрация свечей по категориям
- Регистрация в системе
- Вход в систему

#### Для Покупателя:
- Все функции Гостя
- Добавление свечей в корзину
- Оформление заказа
- Отслеживание статуса заказа
- Оставление отзывов
- Заказ персонализированных свечей
- Чат с мастером
- Управление профилем
- Изменение настроек уведомлений
- Выход из системы

#### Для Мастера:
- Все функции Покупателя
- Добавление новых свечей
- Редактирование своих свечей
- Удаление своих свечей
- Загрузка фотографий
- Просмотр заказов своих изделий
- Ответы на отзывы
- Управление портфолио
- Просмотр статистики продаж

#### Для Администратора:
- Все функции Покупателя
- Управление пользователями
- Модерация свечей
- Управление категориями
- Просмотр всех заказов
- Управление отзывами
- Просмотр статистики системы

#### Для Системы уведомлений:
- Отправка уведомлений о новых заказах
- Отправка уведомлений о новых отзывах
- Отправка уведомлений о статусе заказа
- Отправка системных уведомлений
