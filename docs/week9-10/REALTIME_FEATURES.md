# REAL-TIME ФУНКЦИОНАЛ ДЛЯ ИНТЕРНЕТ-МАГАЗИНА
## Candels Project - Интернет-магазин свечей ручной работы

## Обзор real-time функционала

Real-time функционал Candels включает:
- **Уведомления**: Мгновенные уведомления о новых заказах, отзывах, статусах
- **Чат**: Прямое общение между покупателями и мастерами
- **Синхронизация корзины**: Мгновенное обновление корзины между устройствами
- **Обновления статусов**: Мгновенное отслеживание статусов заказов
