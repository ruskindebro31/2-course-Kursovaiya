## ВВЕДЕНИЕ

Цель работы — разработка веб-приложения для продажи свечей ручной работы с разделением на REST API (backend) и одностраничное клиентское приложение (frontend), а также поддержкой real-time взаимодействия через WebSocket.

**Актуальность:** рынок handmade-товаров растёт; специализированная платформа объединяет мастеров и покупателей, обеспечивая каталог, заказы, отзывы и уведомления в реальном времени.

**Объект исследования:** процессы электронной коммерции в нише handmade-свечей.

**Предмет исследования:** методы проектирования и разработки клиент-серверных веб-приложений на Django и React.

## 1. АНАЛИЗ ПРЕДМЕТНОЙ ОБЛАСТИ И ТРЕБОВАНИЙ

### 1.1 Описание предметной области

Candels — интернет-магазин свечей ручной работы. Пользователи регистрируются, просматривают каталог, добавляют товары в корзину и избранное, оформляют заказы, оставляют отзывы. Авторы (мастера) публикуют свои свечи и управляют ими.

### 1.2 Анализ аналогов

| Аналог | Преимущества | Недостатки |
|--------|--------------|------------|
| Etsy | Большая аудитория | Высокая комиссия, не узкая специализация |
| Wildberries | Масштаб | Нет фокуса на handmade и чате с мастером |
| Локальные мастерские | Персонализация | Отсутствие единой платформы |

**Вывод:** необходима специализированная система с JWT-аутентификацией, SPA-интерфейсом и real-time уведомлениями.

### 1.3 Выбор технологического стека (траектория В)

| Компонент | Технология |
|-----------|------------|
| Backend | Django 4.2, DRF, SimpleJWT |
| Real-time | Django Channels, ASGI |
| Frontend | React 19, Vite, React Router |
| Состояние | TanStack Query, Zustand |
| БД | SQLite (разработка), PostgreSQL (продакшен) |
| Документация API | drf-spectacular (OpenAPI/Swagger) |

## 3. РЕАЛИЗАЦИЯ

### 3.1 Структура проекта

```
Candels/
├── backend/           # Django REST API
│   ├── candels/       # settings, urls, routing (WebSocket)
│   ├── users/         # User, Profile, auth endpoints
│   └── apps/          # candles, orders, cart, reviews, ...
├── frontend/          # React SPA (Vite)
│   └── src/
│       ├── api/       # Axios client, JWT refresh
│       ├── pages/     # маршруты SPA
│       ├── hooks/     # useNotifications (WebSocket)
│       └── store/     # cartStore (Zustand)
└── docs/              # документация КП
```

### 3.2 Backend

- **Модели:** Candle с полем `author`, `is_published`; Order/OrderItem; Cart/CartItem; Review; Favorite; Notification; Chat/Message.
- **API:** ViewSet'ы с пагинацией, SearchFilter, permissions `IsAuthorOrReadOnly`.
- **Auth:** `/api/auth/register/`, `/api/auth/login/`, `/api/auth/token/refresh/`, `/api/auth/profile/`.
- **WebSocket:** `ws/notifications/<user_id>/`, `ws/reviews/<candle_id>/`, `ws/chat/<chat_id>/`.

### 3.3 Frontend

- Маршрутизация: каталог, детальная страница, корзина, заказы, профиль, мои свечи, избранное.
- JWT в localStorage, автоматическое обновление access-токена.
- Оптимистичные обновления: избранное, список отзывов.
- React Query: кэширование запросов каталога и деталей.

### 3.4 Дополнительные функции (траектория В)

- Real-time уведомления через WebSocket.
- Оптимистичный UI при добавлении отзывов и избранного.
- Кэширование данных каталога (staleTime 30 с).
