# План проекта Candels - Траектория В

## Общая информация
- **Траектория**: В (React SPA + AJAX + JWT + WebSocket)
- **Сложность**: Очень высокая
- **Объем кода**: ~5000+ строк
- **Оценка**: «отлично» + автомат на экзамене

## Этапы выполнения проекта

### Этап 0: Инициация и бизнес-анализ (Недели 1-2)
- Выбор темы проекта
- Анализ предметной области
- Определение ключевых сущностей
- Создание бизнес-модели

### Этап 1: Проектирование требований (Недели 3-4)
- Разработка Use Case диаграммы
- Создание доменной модели
- Детализация функциональных требований

### Этап 2: Архитектурное проектирование (Недели 5-6)
- Проектирование архитектуры клиент-серверного приложения
- Определение API endpoints
- Проектирование системы аутентификации

### Этап 3: Проектирование базы данных (Недели 7-8)
- Создание ER-диаграммы
- Определение таблиц и связей
- Создание DDL-скриптов

### Этап 4: Создание и настройка проекта Django (Недели 9-10)
- Настройка виртуального окружения
- Создание Django проекта
- Конфигурация settings.py

### Этап 5: Реализация моделей и админ-панели (Недели 11-12)
- Создание моделей данных
- Реализация миграций
- Настройка Django Admin

### Этап 6: Реализация API и JWT-аутентификации (Недели 13-14)
- Создание REST API endpoints
- Реализация JWT-аутентификации
- Настройка разрешений

### Этап 7: Разработка React-приложения + WebSocket (Недели 15-16)
- Разработка UI компонентов
- Интеграция с REST API
- Реализация WebSocket для real-time уведомлений

### Этап 8: Завершение и документация (Недели 17-18)
- Тестирование и отладка
- Подготовка документации
- Финальная проверка

## Технические требования

### Backend (Django REST API)
- Django 4.2+
- Django REST Framework
- JWT Authentication
- Django Channels для WebSocket
- SQLite/PostgreSQL база данных

### Frontend (React SPA)
- React 18+
- React Router
- React Query для кэширования
- Axios для HTTP запросов
- Socket.IO client для WebSocket
- JWT decode для токенов

## Дополнительные функции траектории В
1. Расширенная клиентская логика (оптимистичные обновления, кэширование)
2. Дополнительный функционал: WebSocket (Django Channels), real-time уведомления
3. Продвинутая работа с API (пагинация, фильтрация, поиск на клиенте)
4. Система комментариев с моментальным отображением
5. Система избранного с оптимистичным обновлением UI
