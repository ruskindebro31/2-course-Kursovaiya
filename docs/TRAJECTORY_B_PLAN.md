# 🧭 Траектория В: React SPA + AJAX + JWT + WebSocket

## 📅 Неделя 7–8: Backend API + JWT
- Созданы модели: `User`, `Profile`, `Candle`, `Order`, `CartItem`, `Review`, `Notification`, `Chat`, `Message`
- API реализован через DRF:
  - `/api/users/` — управление пользователями
  - `/api/candles/` — каталог
  - `/api/orders/` — заказы
  - `/api/cart/` — корзина
  - `/api/reviews/`, `/api/notifications/`, `/api/chats/`
- JWT-аутентификация:
  - `POST /api/token/` — получить токен
  - `POST /api/token/refresh/` — обновить
  - `GET /api/users/me/` — текущий пользователь
